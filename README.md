# Breakdown Dashboard

Веб-приложение для отображения данных о поломках оборудования.  
Данные передаются из 1С на backend по HTTP API, сохраняются в Supabase и отображаются на frontend.

## Стек

Frontend:
- React
- Vite
- Bootstrap
- DataTables

Backend:
- Node.js
- Express
- Supabase
